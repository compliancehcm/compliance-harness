# Button

Every action in the Portal. Solid buttons are 600 weight; hover darkens to --primary-hover, secondary hover fills with --muted. No shadows, no focus ring beyond the browser default.

```jsx
<Button size="lg" onClick={enviar}>Solicitar férias</Button>
<Button variant="secondary" size="sm">Rejeitar</Button>
<Button variant="onPrimary">Registrar ponto</Button>
```

Pairs read Rejeitar (secondary) then Aprovar (primary), 6px apart.
