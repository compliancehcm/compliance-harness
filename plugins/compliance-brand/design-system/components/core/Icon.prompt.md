# Icon

Stroke icon set copied from the Portal do Trabalhador source — use it instead of pasting raw SVG.

```jsx
<Icon name="holerite" size={16} />
```

Names: dash, ponto, holerite, ferias, vagas (the five nav icons), plus olho, painel, menu, sino, check, sair, sso. Always 24×24 geometry, stroke-width 2, round caps, `currentColor`. Need a glyph that is not here? Take it from Lucide at the same weight.
